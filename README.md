# ProjektovyTyden

Unity project for Projektový Týden.

## Requirements

- **Unity 6000.3.9f1** (Unity 6)
- Git

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Pluhec/ProjektovyTyden.git
```

### Switch to your team branch

```bash
git checkout <your-branch>
```

Available team branches:
- `SimulaceUnity` — Simulation team
- `PlayerChoices` — Player choices team
- `Web` — Web team

### Open in Unity

1. Open **Unity Hub**
2. Click **Open** → select the cloned folder
3. Make sure you're using Unity **6000.3.9f1**

## Project Structure

```
Assets/          — Game assets, scenes, settings
Packages/        — Unity package manifest
ProjectSettings/ — Unity project configuration
```

## Git Workflow

- Each team works on their own branch
- **Do not** push directly to `main` — use pull requests
- Always pull before starting work:
  ```bash
  git pull origin <your-branch>
  ```

## .gitignore

The project includes a `.gitignore` that excludes:
- `Library/`, `Temp/`, `Logs/`, `UserSettings/` (auto-generated by Unity)
- Build outputs
- IDE files (`.vs/`, `.idea/`)
